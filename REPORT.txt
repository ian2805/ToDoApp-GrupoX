# Informe del Grupo 1

1. Pasos realizados:
- Creamos el repositorio ToDoApp-Group1 en GitHub.
- Cada miembro creó una rama (ian, luis, luisian).
- Implementamos funcionalidades y resolvimos conflictos.
- Fusionamos todas las ramas en group-1 y luego a main.

2. Comandos Git:
- git clone <URL>: Clonar el repositorio.
- git checkout -b ian: Crear rama.
- git add <archivo>: Añadir cambios.
- git commit -m "mensaje": Hacer commit.
- git push origin ian: Empujar rama.
- git merge luisian: Fusionar rama conflictiva.
- git push origin --delete ian: Eliminar rama.

3. Conflictos:
- Conflicto en task_model.py entre is_completed/is_done y métodos mark_as_complete/set_done.
- Solución: Mantuvimos is_completed como atributo principal y combinamos los métodos.
